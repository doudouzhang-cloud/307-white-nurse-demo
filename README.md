# 307白护士长demo

独立演示版本。以 307 项目为基础，参考术后随访页面的信息层级，将院外复查、量表、导管照护和每日健康记录整合到患者端“今日任务与院外照护”时间线。患者从助手首页的“今日院外照护”或左侧流程第 05 步进入；医生从主任工作台的“院外预警”进入处理页。

此版本使用独立的浏览器存储键和报告附件数据库，不读取或修改原 307 项目演示数据。页面中的患者、报告、预警、联系请求和医生操作均为虚构演示；没有真实医院接口、消息或电话服务。

本版暖色医护团队卡通插画位于 `assets/medical-illustrations/team-warm-cartoon.png`，用于患者时间线、团队绑定卡和主任工作台。
